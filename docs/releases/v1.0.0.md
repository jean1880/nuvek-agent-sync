# nuvek-agent-sync 1.0.0

The first public release of `agent-sync`: render one authored agent-config checkout into Claude
Code, Antigravity and Codex, and gate drift.

## Highlights

- **One source, three tools.** Rules, skills, agents, MCP servers, permissions, hooks and model
  tags are rendered into each tool's native configuration. Files a tool co-owns are merged.
- **`check` gates drift.** It is read-only and exits 6 when anything differs from the source. On
  a fresh machine a missing tool file is reported as drift, and `apply` creates it.
- **Private overlays.** `--overlay <path>` (or `$AGENT_SYNC_OVERLAY`) layers a private checkout
  over a public base. Files are resolved path by path with the overlay winning, the TOML sources
  are merged by key, and an overlay can remove base entries explicitly. With no overlay, the output
  is unchanged.
- **Careful writes.** Each file is replaced atomically, from an exclusive temporary, and keeps
  a `.agent-sync.bak`. Writes stay inside the managed tool directories, never pass through a
  symlink, refuse secret-shaped content, and run one at a time under a lock. Only what
  `managed.json` records is ever deleted. Antigravity's settings are not written while `agy`
  runs unless you pass `--force`.
- **Scrubbed output.** Everything printed, error chains included, is redacted.
- **Your names, not ours.** The Claude plugin link takes its name from your
  `.claude-plugin/plugin.json`, the source path comes from `--dir` / `$AGENT_CONFIG_DIR`, and
  every home-relative path comes from `$HOME`.

## Exit codes

0 in sync · 2 usage · 4 source missing · 5 refused · 6 drift or an apply that could not converge ·
7 invalid secret-surface configuration.

## Install

Download the static x86_64 Linux binary or the `.deb` from this release and check it against
`SHA256SUMS`. To page on drift from systemd with `OnFailure=`, see
[Paging on drift from systemd](../operations.md#paging-on-drift-from-systemd).
